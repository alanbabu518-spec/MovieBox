# MovieBox

MovieBox is a production-oriented full-stack movie discovery platform built with React, Node.js, Express, PostgreSQL, Redis, and AI.

## Architecture

- Frontend: React + TypeScript
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Cache and queues: Redis
- External movie data: TMDB
- AI: LLM API
- Deployment: Docker + CI/CD

## Project Structure

- client - React frontend
- server - Node.js backend
